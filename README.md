# 比特币定投记录工具

这是一个用于记录和管理比特币定投的工具，支持本地存储和云端数据库同步。

## 功能特点

- 记录定投信息：日期、买入金额、BTC价格、备注等
- 支持美元(USD)和人民币(CNY)两种货币单位
- 自动获取当前BTC价格
- 实时计算收益率和投资统计
- 数据可视化：展示投资走势、BTC价格走势、累计持有量和收益率变化
- 数据导入导出功能
- 支持本地存储和MySQL数据库存储

## 技术栈

- 前端：HTML, CSS, JavaScript, Chart.js, Axios
- 后端：Node.js, Express, MySQL

## 如何运行

### 前提条件

- Node.js (v14+)
- MySQL 数据库 (可选，如果需要云端存储)

### 安装步骤

1. 克隆或下载代码库

2. 安装依赖
```bash
npm install
```

3. 配置数据库 (可选)
   - 确保MySQL服务运行
   - 在MySQL中创建名为`bitcoininvestment`的数据库
   - 如需修改数据库配置，可以编辑`.env`文件或在应用界面中设置

4. 启动服务器
```bash
npm start
```
或开发模式:
```bash
npm run dev
```

5. 访问应用
   - 打开浏览器，访问 `http://localhost:3000`

## 使用说明

### 基本操作

1. **添加记录**：填写日期、金额、BTC价格和备注，点击"保存记录"
2. **查看统计**：应用自动计算总投资额、总BTC数量、当前价值、收益率等指标
3. **查看图表**：可视化展示投资走势、BTC价格、持有量和收益率变化

### 高级功能

1. **数据导出**：点击"导出数据"按钮，将记录导出为JSON文件
2. **数据导入**：
   - 点击"导入文件"按钮导入JSON文件
   - 点击"导入JSON文本"按钮，粘贴JSON数据

3. **数据库同步**：
   - 切换到"云端"模式启用数据库功能
   - 点击"数据库配置"设置数据库连接参数
   - 使用"同步到云端"或"从云端同步"按钮进行数据同步

## 注意事项

- 默认使用本地存储模式，数据保存在浏览器的localStorage中
- 启用云端模式前，确保数据库配置正确且能够连接
- 建议定期导出数据作为备份
